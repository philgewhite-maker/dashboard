Google Photos albums

Name albums Name_Location_Date_Other, leaving any slot empty if it doesn't apply: Kat_ (default album), Kat_Lisbon, Kat_x (private), Alena__2026_Birthday (no location — note the double underscore). Only the second slot ever becomes a location tag, so a date or a word like “Birthday” can't be filed as a place. The trailing underscore keeps Kat_ from matching Katerina_, and makes them searchable in Photos.

Google has no API for albums, so run the snippet below in the browser console (F12 → Console) on photos.google.com/albums, then paste the result here. Run it on /people too and it also lists faces Google knows about that have no album yet. Album links are permanent, unlike the face-group links tried previously.
Show the console snippet 
(async () => {
  // Accumulates across pages: run on /albums, then on /people, then paste.
  window.__dash = window.__dash || { albums: new Map(), people: new Set() };
  const onAlbums = location.pathname.includes('album');
  const grab = () => {
    // Verified against the live page: each album has TWO anchors sharing an
    // href (a cover tile and a text tile), aria-label is absent, and the
    // cover is a CSS background-image on a descendant, not an img. So both
    // anchors are merged by URL, keeping whichever piece each one carries.
    document.querySelectorAll('a[href*="/album/"]').forEach(a => {
      const url = a.href.split('?')[0];
      const lines = (a.innerText || '').split('\n').map(s => s.trim()).filter(Boolean);
      let cover = '';
      for (const el of a.querySelectorAll('*')) {
        const b = getComputedStyle(el).backgroundImage;
        if (b && b.includes('usercontent')) { cover = b.slice(5, -2); break; }
      }
      // The grid requests tiny thumbnails (often 24px); ask for a usable one.
      if (cover) cover = cover.replace(/=s\d+/, '=s400');
      const titleLine = lines.find(l => !/^(no items|\d+\s*items?|more options)$/i.test(l));
      const countLine = lines.find(l => /^\d+\s*items?$/i.test(l));
      const prev = window.__dash.albums.get(url) || {};
      window.__dash.albums.set(url, {
        url,
        title: prev.title || titleLine || '',
        count: prev.count || (countLine ? parseInt(countLine, 10) : 0),
        cover: prev.cover || cover,
      });
    });
    document.querySelectorAll('a[href*="/search/"]').forEach(a => {
      const t = (a.getAttribute('aria-label') || a.textContent || '').trim();
      if (t && /QUYxUWlw/.test(a.href) && !/^Photo|\d{1,2}:\d{2}/.test(t)) window.__dash.people.add(t);
    });
  };
  const box = [...document.querySelectorAll('div')]
    .filter(d => d.scrollHeight > d.clientHeight + 500 && d.clientHeight > 200)
    .sort((a,b) => b.scrollHeight - a.scrollHeight)[0] || document.scrollingElement;
  box.scrollTop = 0;
  await new Promise(r => setTimeout(r, 400));
  // Small fixed steps: big jumps skip rows this grid has already recycled.
  for (let y = 0; y < box.scrollHeight; y += 220) {
    grab();
    box.scrollTop = y;
    await new Promise(r => setTimeout(r, 320));
  }
  grab();
  const out = {
    albums: [...window.__dash.albums.values()].filter(a => a.title),
    people: [...window.__dash.people],
  };
  if (onAlbums && out.albums.length === 0) {
    // Google changes this markup from time to time. Rather than fail
    // silently, show what IS on the page so the selector can be corrected.
    const sample = [...document.querySelectorAll('a')].slice(0, 40)
      .map(a => a.getAttribute('href')).filter(Boolean);
    console.warn('No albums matched. Paste this back to Claude:', JSON.stringify(sample));
  }
  const json = JSON.stringify(out, null, 1);
  // copy() is a DevTools convenience global, injected only into a console
  // opened directly in that panel — it throws ReferenceError anywhere else
  // (a docked/undocked console reattached differently, remote debugging,
  // some extensions' console proxies). Clipboard API needs a secure context
  // AND focus, neither guaranteed right after pasting into DevTools, so this
  // tries three ways and always leaves the JSON visible either way.
  let copied = false;
  try { copy(json); copied = true; } catch (e) { /* not in a real DevTools console */ }
  if (!copied) {
    try { await navigator.clipboard.writeText(json); copied = true; } catch (e) { /* no clipboard permission/focus */ }
  }
  console.log(`${copied ? 'Copied' : 'Could not auto-copy — select the JSON below and copy it manually:'} `
    + `${out.albums.length} albums and ${out.people.length} faces.`
    + (onAlbums ? ' Now run this again on /people to spot people with no album.' : ''));
  if (!copied) console.log(json);
})();

Business Ideas

Settings

Connections — rating categories

The detailed star ratings shown on every connection. Removing one clears every rating already given under it — there's no way back from that, so it asks first.

Photo sync

Photos added before task attachments existed live only on the device that added them — their ids sync, but the images don't, so a connection imported on the desktop shows initials instead of a face on the phone. This uploads them to your own server (the same one as live sync and attachments) so they appear everywhere. Safe to re-run, and safe to stop partway.

AI features

Stored only in this browser's local storage on this device — never synced, never sent anywhere except directly to api.anthropic.com. You'll need to enter it again on each device. Calls are billed to your own account (typically a fraction of a cent per screenshot). Get a key →
API usage this month

Tidy up tags

Every tag value in use, with how many connections have it. Values differing only by capitalisation or spacing are flagged for one-click merging; anything else can be renamed or merged by hand. Changes apply across all connections.

Google Contacts

Matching reads your contacts. Writing back is a separate, much broader permission — it can change and clear fields in your real address book — so it's off unless you turn it on here.

Private fields

Off by default. This only controls what's shown on this device — anything already recorded stays saved and still syncs; it just isn't displayed, grouped, or searchable while hidden.

Live sync (your own server)

Saves changes to your own hosting automatically, a couple of seconds after you stop typing, and picks up changes from your other devices. No sign-in, so nothing expires. Leave both boxes empty to stay on manual Google Drive push/pull below.
Stored only on this device, never exported in a backup and never committed to the repo. Enter the same pair on each device you use.
